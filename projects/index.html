Geospatial Rental Market Analysis

GitHub

Built a Python pipeline combining SanGIS, RentCast API, and OpenStreetMap data to study rental pricing around UC San Diego. The pipeline processed more than 4,900 listings and 133 sampled locations, including distances to nearby amenities.

Compared regression models using AIC and BIC, calibrated a 95% conformal prediction interval, and evaluated university housing within the same pricing framework as the surrounding rental market.

Cross-Modal Music Recommender

GitHub

Built with a teammate outside coursework, this application recommends music that matches an image’s atmosphere. BLIP produces an image caption, and CLAP connects the resulting mood description to audio using embedding-based retrieval.

The system precomputes 512-dimensional embeddings for approximately 100 curated tracks and ranks recommendations by cosine similarity. A Gradio interface supports image uploads, configurable results, and audio playback.

Synth-Pop Symbolic Music Generation

GitHub

A team project using PyTorch, LSTMs, and Markov baselines to generate symbolic music from a curated synth-pop MIDI dataset. The work covered melody and drum generation from scratch, plus bass and drum generation conditioned on melody and tempo.

Evaluation included validation perplexity, comparison with the Markov baseline, pitch-class distributions, and sampling-temperature experiments. The generators produced playable MIDI files.

In-Memory Parking Ticket Database

GitHub

A C command-line database built for UC San Diego’s CSE 30 course. Used a hash table, separate chaining, and linked lists to insert, delete, and look up vehicle and ticket records, track fine totals, and manage heap allocation and cleanup with malloc and free.
